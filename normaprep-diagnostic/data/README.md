# Référentiel du diagnostic

Ce dossier contient les fichiers JSON du référentiel, importés depuis
*NormaPrep Diagnostic › Référentiel* dans l'administration WordPress.

Le plugin est livré avec un **référentiel de démonstration** (version
`demo-0.1` : 3 sous-thèmes, 4 questions, 5 questions de profilage, 5
réglementations), qui permet d'essayer l'espace consultant dès
l'installation. Il sera remplacé par les fichiers produits par le pipeline
de contenu : il suffit de les déposer ici à la place et de relancer l'import.
Les éléments de démonstration absents des nouveaux fichiers seront alors
supprimés, ou désactivés s'ils ont servi dans un diagnostic.

Format des fichiers : [FORMAT.md](FORMAT.md).
